- Unified object model
- Custom object registration
- SEM/SEMJ
- Native-library objects
- PortaPy runtime objects
- Differential testing

- Contact debug drawing
- CPython/asmpython parity snapshots

- Scene Tree panel
- Properties panel generated from reflection
- Asset browser
- Undo/redo UI
- Play and Play Here
