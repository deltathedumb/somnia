# Contributing

By contributing source code to Somnia, contributors agree that their contribution may be distributed as part of Somnia under the Mozilla Public License 2.0.

1. Keep editor and runtime features on the unified object model.
2. Add CPython tests for every behavior.
3. Add or extend a parity snapshot when behavior is compiler-sensitive.
4. Report CPython-pass/asmpython-fail cases as compiler compatibility failures.
5. Do not add Luau as a planned scripting backend.
6. Preserve required third-party copyright and license notices.
7. Do not copy code into Somnia unless its license is compatible with MPL-2.0 and the required attribution is recorded.

See [Licensing](licensing.md) for Somnia's project licensing model.
